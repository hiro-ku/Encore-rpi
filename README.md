# Encore-rpi
Wav file play back using cjmcu-1334 and Raspberry Pi Pico 2W
these files are stored on the flash of the Pico 2W 

i have created these files using the voice bank of Kasane Teto Synth V 
as of 21/8/2025 ive attached 3 .h files in audio data 
when you run the encore.ino it will create a folder into the arduino folder paste the .h file there the one you want to use 
and change its name to "audio_data.h"
